# Driver Matcher

Этот проект реализует поиск **пяти ближайших водителей** к заказу на прямоугольной карте с помощью **трёх разных алгоритмов**.  
Также включены **юнит-тесты** и **бенчмарк** для измерения производительности.

## 📁 Структура проекта

- `DriverMatcher` — основная логика: класс `Driver`, алгоритмы поиска.
- `Benchmark` — измерение производительности алгоритмов.
- `Tests.NUnit` — юнит-тесты.

## 🧠 Алгоритмы

1. **Сортировка (Sort)**  
   - Полностью сортирует всех водителей по расстоянию до заказа.
   - Сложность: `O(N log N)`
   - Простой, но медленный при большом количестве водителей.

2. **Поиск по радиусу (Radius)**  
   - Увеличивает радиус вокруг заказа, пока не найдёт 5 водителей.
   - Сложность: `O(N * R)`, где `R` — количество итераций.
   - Может быть быстрее сортировки при плотном расположении водителей.

3. **Top-K (Top-K)**  
   - Поддерживает список из 5 ближайших водителей за один проход.
   - Сложность: `O(N)`
   - Наиболее эффективный при малом `K`.

## 🧪 Тесты

- Покрыты **юнит-тестами** с использованием **NUnit**.
- Проверяются:
  - Корректность расчёта расстояний.
  - Правильность работы всех трёх алгоритмов.
  - Граничные случаи (пустой список, меньше 5 водителей и т.д.).
